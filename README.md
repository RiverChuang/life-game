# 人生遊戲 v0.8.0（積木小鎮・人生養成・3–99 歲）

原創溫馨療癒畫風的 2D 人生模擬遊戲。全部免費、不需安裝任何軟體。

## 這一版有什麼

- **生涯規劃**：33 種職業（含醫師、公務員、自己開店）都能設為目標；每種職業有路線圖（學歷、科系、能力、技能、考試、實習）與「下一步怎麼做」，還能預覽未來生活：各職位薪水、壓力、存頭期款要幾年、退休金
- **職業挑戰模式**：標題畫面選「🎯 職業挑戰」，挑一種職業直接從剛入行開始，挑戰 7 項目標（升到最高職位、買房、成家……），65 歲或退休時結算星星
- **各行各業的工作挑戰**：入行後會遇到該職業專屬的狀況與抉擇，表現好就更快升遷
- **從 3 歲開始**：人生從 3 歲生日開始到 99 歲；建立角色時直接分配 3 歲時的六項能力（每項 40 起、最高 80，家境越好點數越少），遊戲裡的數值就是你分配的數字
- **選學校**：幼兒園（公立／雙語／森林）、國小（學區／私立／實驗）、國中（學區／私立／音樂班／體育班／數理資優班）、高中班別（普通／數理資優／語文資優／美術／體育），高職與五專自己選科別；各有門檻與不同成長
- **職業規劃**：「抉擇」→「職業規劃」看每種職業的錄取條件，設定目標後找工作會優先出現
- **升遷條件**：「理財」的工作區塊列出升到下一個職位需要的年資、表現、能力與技能，達成後可在「抉擇」申請升遷
- **技能等級**：練習 25 次升初級、50 次中級、75 次高級、100 次專業級（每排一天算一次）
- 修正手機上背景音樂沒有聲音的問題（iPhone 靜音鍵開著也能播放）
- **背景音樂**：原創輕快旋律，用瀏覽器即時合成（不需要音樂檔）；右上角 🎵 開關，選單可調音量
- **銀行**：12 歲起可存款、提款，存款每月有利息；20 歲起有收入就能申請信用貸款，可提前還清
- **定期定額基金**：每月投入金額自己決定（可輸入任意金額或依收入比例），也能單筆投入、隨時贖回
- **股票市場**：9 檔虛構公司與指數基金，股價每週變動、7 月發股利，18 歲起可買賣（紅漲綠跌）
- **父母婚姻**：爸媽會不會離婚是隨機的，之前常有吵架的預兆，你的應對也會有影響
- **積木玩具風人偶**：原創的方頭方身人偶，從嬰兒長到白髮老人，髮型、髮色、膚色、衣服都能變
- **每週七天自己排**：星期一到日，每天決定要做什麼（平日是放學或下班後，週末是整天）；可以一次套用到整個平日或週末
- **國、英、數、社、自五科**：各科分開算成績，想加強哪科就排哪科，還有數學、理化補習班與作文班；原本的鋼琴、游泳、程式等才藝課也都在
- **小鎮自由走動**：俯視小鎮地圖，點地點讓角色走過去；地圖上的「！」是這週的事件，路上遇到的朋友家人可以直接約
- **自己決定人際關係**：和誰聊天、吃飯、出遊、約會、告白、分手，都由你選
- **依收入買房、買東西**：四種等級的租屋與買房，加上手機、電腦、機車、汽車、鋼琴、寵物等二十多種商品，每樣都有實際效果與每月開銷
- 人生走到 99 歲；舊版存檔可以讀取並接著用新玩法玩

## 在電腦上先試玩

1. 把 zip 解壓縮。
2. 打開資料夾，雙擊 `index.html`，會用瀏覽器開啟遊戲。
3. 不需要網路也能玩（沒網路時字型會改用電腦內建字型）。

## 上傳到 GitHub Pages（讓手機也能玩）

1. 登入 GitHub，右上角「＋」→「New repository」。
2. Repository name 填 `life-game`，選 **Public**，按「Create repository」。
3. 在新倉庫頁面點「uploading an existing file」。
4. 把解壓縮後資料夾裡的**所有內容**（`index.html`、`manifest.webmanifest`、`sw.js`、`README.md`、`css`、`js`、`icons`）一起拖進上傳區。
   注意：拖的是資料夾「裡面」的東西，不是外層資料夾本身。
5. 按綠色的「Commit changes」。
6. 到倉庫上方「Settings」→ 左側「Pages」。
7. 「Branch」選 `main`、資料夾選 `/ (root)`，按「Save」。
8. 等 1–2 分鐘，重新整理該頁，上方會出現網址：
   `https://你的帳號.github.io/life-game/`

之後更新版本：在倉庫頁面「Add file」→「Upload files」，把新版的所有檔案與資料夾一起拖進去覆蓋，按「Commit changes」。一兩分鐘後重新整理遊戲網址就是新版。

## 安裝到手機

上傳到 GitHub Pages 後：

- **iPhone／iPad**：用 Safari 打開遊戲網址 → 下方「分享」→「加入主畫面」→「新增」。
- **Android**：用 Chrome 打開遊戲網址 → 右上角「⋮」→「安裝應用程式」或「加到主畫面」。

裝好後會有自己的圖示、全螢幕開啟；打開過一次之後，沒有網路也能玩。
之後上傳新版本，連上網路再打開一次（關掉重開）就會自動更新。

## 檔案結構

```
index.html            遊戲入口
manifest.webmanifest  安裝到手機的設定（名稱、圖示、全螢幕）
sw.js                 離線快取（沒網路也能玩）
icons/                遊戲圖示
css/style.css         畫面樣式
js/engine.js          遊戲規則與狀態（不碰畫面）
js/jobs.js            職業卡（33 種）
js/activities.js      每天行程的活動（110 多種）
js/shop.js            商店商品與房屋
js/town.js            小鎮地圖
js/music.js           背景音樂（即時合成）
js/events/*.js        事件庫（依年齡與主題分檔，共 800 多則）
js/art.js             2D 美術：人物、場景、表情（全部用程式碼繪製）
js/save.js            存檔（目前存在瀏覽器）
js/ui.js              畫面與操作
```

## 存檔說明

- 每週自動存檔；選單裡有 10 個手動存檔欄位。
- 存檔目前存在「這台裝置的這個瀏覽器」裡。換裝置請用「匯出存檔檔案」備份。
- Google 雲端硬碟同步會在里程碑 4 加入。

## 操作小技巧（電腦版）

- 空白鍵或 Enter：下一則事件／開始這週／結束這週／下個月
- 數字鍵 1–9：選擇目前事件的選項
